REVIGORAR - FRONTEND

1. Instale Node.js 18+.
2. Abra este diretório no terminal.
3. Rode: npm install
4. Confira o arquivo .env:
   VITE_API_URL=http://localhost:3000/api
5. Rode: npm run dev
6. Abra: http://localhost:5173

O cadastro foi corrigido para enviar full_name, que é o nome esperado pelo backend.
