REVIGORAR FRONTEND

1. Abra o terminal nesta pasta.
2. Confirme o arquivo .env:
   VITE_API_URL=http://localhost:3000/api
3. Instale as dependências:
   npm install
4. Inicie:
   npm run dev

Abra http://localhost:5173

O frontend não usa mockData.js nem dados de demonstração como fallback.
As páginas autenticadas usam exclusivamente a API.

AVALIAÇÕES
- Acesse /avaliacoes.
- A aba "Ver avaliações" lista somente avaliações salvas no banco.
- Clique em "Ver avaliação" para abrir os dados completos.
- "Gerar PDF" abre a impressão A4; no diálogo do navegador escolha "Salvar como PDF".

Fotos são enviadas como multipart/form-data para o backend e exibidas a partir de /uploads.
